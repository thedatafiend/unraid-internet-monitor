# unraid-internet-monitor

A lightweight Docker app for Unraid that continuously measures internet connection
quality to your ISP and beyond. It tracks latency, jitter, packet loss, outages,
DNS/HTTP health, and scheduled speed tests. It keeps 30 days of history and serves
a web UI you can reach on your LAN and over Tailscale.
